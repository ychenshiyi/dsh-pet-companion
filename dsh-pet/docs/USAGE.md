> 适用：dsh-pet 独立伴侣版（P6 阶段）
> 最后更新：2026-10-28
> **维护约定：每次新增 / 修改功能，必须同步更新本文档（尤其「功能」「设置项」「已知限制」「变更记录」四节）。**

## 1. 这是什么

在 dsh-pet 原有桌宠（动画、拖拽、右键菜单、多宠物）基础上，加了一套**不依赖 DSH Desktop** 的伴侣能力：

- 独立 Electron 应用：自带本机 HTTP 服务、设置中心、桌面透明窗
- 文本对话：DeepSeek（或任意 OpenAI 兼容 / Anthropic 接口），生成过程中气泡文字会逐步变长（1s 轮询的气泡式流式）
- 语音对话：LiveKit + 本地 Agent（SenseVoice 识别 → DeepSeek → Edge TTS）
- 统一记忆：文本与语音共用同一份 `memory.json`

## 2. 启动

### 开发期（当前）

```bat
cd dsh-pet-repo\dsh-pet
scripts\app.cmd
```

`app.cmd` 自动设置并打印：

| 变量                    | 含义                | 默认                                             |
| ----------------------- | ------------------- | ------------------------------------------------ |
| `DSH_PET_HOME`          | 桌宠数据根          | `<项目>/data/dsh-pet`                            |
| `DSH_PET_LIVEKIT_BIN`   | livekit-server.exe  | `<项目>/voice/livekit_1.13.11_windows_amd64/...` |
| `DSH_PET_PYTHON`        | Agent 的 Python     | `<项目>/voice/.venv/Scripts/python.exe`          |
| `DSH_PET_AGENT_ROOT`    | `agent/` 的父目录   | `<项目>/voice`                                   |
| `DSH_PET_ELECTRON_PATH` | Electron 可执行文件 | `~/.dsh/electron/electron.exe`                   |

已存在的同名环境变量优先。首次启动会从 `~/.dsh/dsh-pet` 复制配置与素材到 `DSH_PET_HOME`。

> 打包版（P6）会把上面这些收进安装包与设置页，届时无需环境变量。

## 3. 首次配置

1. 右键桌宠 →「**打开设置**」（独立 Electron 窗口，不经 Edge）
2. 「模型」页：
   - Base URL：`https://api.deepseek.com/v1`
   - 模型：`deepseek-chat`
   - API Key：填入后点「测试连接」→ 成功再「保存设置」
3. 「对话」页可改上下文存储目录；默认 `DSH_PET_HOME/conversations/memory.json`，首次自动从旧 `memory.json` 迁移
4. 「语音」页：引擎 Edge TTS、音色、语速/音调/音量
5. 「LiveKit」页：内置模式、端口 7880、房间 `pet-room`

> 设置页地址含一次性访问令牌（`#token=...`），**不要手工去掉**；令牌失效时从右键菜单重新打开。

## 4. 右键菜单

| 菜单项                  | 说明                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| 打开设置 / 情感 / 心情… | 在**独立 Electron 窗口**打开统一设置中心，不经过 Edge/系统浏览器 |
| 查看余额                | 独立模式不可用（需要 DSH）                                       |
| **对话**                | 文本对话（共用记忆）                                             |
| **语音对话（常开）**    | 开关常开语音；**右侧 ✓ 表示当前已开启**（来自主进程的真实状态）  |
| 语音设置、显示位置      | 已移除；统一到「打开设置」的「语音」「显示」标签                 |
| 重载配置                | 重启桌面 Helper 并重建窗口                                       |

> 如果宠物被切成「都不」，右键菜单也会消失——用**系统托盘**把「桌面位」勾回来。

## 5. 语音对话

- 开启：右键「语音对话（常开）」→ 后台自动拉起 LiveKit + Agent（约 10–20 秒）
- 说话：说完停约 0.6 秒，Agent 回答；可随时打断
- 关闭：再次点同一项，或设置页 LiveKit 页「停止语音服务」
- 空闲 5 分钟自动回收（LiveKit/Agent 进程退出）
- 状态：连接后气泡显示「🎤 我在听」；用户说话时「在听你说…」，停顿后「我在想…」，Agent 说话时显示字幕
- **语音常开**：开启后可直接对话；关闭后语音窗/Mic/LiveKit/Agent 全部停止，不能再进行语音对话
- **唤醒词**：超过「空闲多少秒」（默认 10 秒）没有对话，下一句必须包含唤醒词（默认「小鱼」）才会进入对话；非唤醒词会被丢弃，不生成回复
- 字幕：Agent 说话时最终转写会以气泡显示在桌宠上（隐藏语音窗不可见），时长约 8 秒
- **延迟优化（2026-10-28）**：VAD 静音 0.30s、端点 0.35s、TTS 按短句分段合成（第一段先出声）、回复上限 120 tokens
- 音色：默认 **Edge TTS `zh-CN-XiaoxiaoNeural`**（音色更自然）；MeloTTS 作离线备选
- **情感韵律**：每句合成前按当前心情微调，不再是固定语调：

  | 心情 | Edge 语速/音调 | Melo 语速 |
  | ---- | -------------- | --------- |
  | 开心 | +6% / +3Hz     | ×1.08     |
  | 害羞 | -4% / +1Hz     | ×0.96     |
  | 低落 | -8% / -3Hz     | ×0.90     |
  | 生气 | +5% / +2Hz     | ×1.05     |
  | 疲惫 | -10% / -4Hz    | ×0.85     |
  | 平静 | 基准           | ×1.00     |

  偏移叠加在设置页的基准语速/音调上；改心情后下一句生效。

- 试听：语音页选音色 → 填一句 →「试听」，会调用本机合成并直接播放
- 延迟参考：STT ~0.15s、LLM 首字 ~1s、TTS 1.8–2.5s（Edge）/ 0.5–1.5s（MeloTTS），说完到出声约 2–4 秒
- 网络不稳时 Edge 可能失败；Agent 会按 `Edge → MeloTTS`（或反向）自动回退（需本地模型）

## 5.1 情感养成（P6 v1）

- 状态：好感 / 信任 / 熟悉 / 精力（0–100）+ 当前心情（开心/平静/害羞/低落/生气/疲惫）
- 每轮对话后用**本地启发式**更新（不额外调用 LLM，不增加 token）：正向词加好感/信任，负向词降低；精力随聊天缓慢下降
- 记忆：`episodes`（最近情节，最多 120 条）、`facts`（从「我叫…/我生日是…/我喜欢…」等自述抽取，去重）、`insights`（每 6 段情节或 12 轮生成一条成长日志）
- 提示词：关系数值 + 最近事实会拼进 system，让称呼/语气随关系变化
- 情绪动画：心情变化时自动播放已有动画（开心→开心跃动、害羞→害羞惊讶、生气→傲娇生气、低落→发呆、疲惫→打瞌睡）；不新增素材
- 文本与语音共用 `emotion.json`：语音会话启动时读状态注入提示词，回合结束写回
- 关闭：设置「情感」页取消启用（需重启应用）；重置：同页「重置成长」
- 边界：不根据情绪做付费引导/情感操纵；原始音频不落盘；主动关心默认关（P6 只留开关）

## 5.2 陪伴功能（用量 / 主动 / 提醒 / 回忆录 / 快捷回复 / 多宠物）

### 用量与费用

- 文本：按模型返回的真实 token 记账；语音：按每轮转写/回复字符估算（v1）
- 「陪伴」页查看今日/近 7 天、文本/语音拆分、调用次数
- 可设每日 token 上限与提醒阈值（默认 80%）；到阈值会附在回复气泡里
- 可填每 1k token 估算价（元），面板显示约合人民币

### 主动关心（默认关）

硬闸门全部通过才会主动说话：

- 专注模式关闭
- 主动关心开启
- 不在安静时段（默认 23:00–08:00，可跨午夜）
- 当日主动次数未超上限（默认 2）
- 距上次主动至少 N 分钟（默认 120）
- 宠物 `whisperEnabled` 与独立模式授权仍然有效

手动「碎碎念」不受这些闸门限制。

### 专注模式

- 关闭主动关心；可选「同时关闭语音」（保存后立即停语音）
- 取消勾选即恢复，不删除数据

### 提醒 / 日程

- 「陪伴」页填内容 + 时间，到点由桌宠气泡提醒（`⏰ ...`）
- 15 秒检查一次；断网也能响；可在列表删除
- 提醒存 `conversations/reminders.json`

### 回忆录

- 「情感」页或「陪伴」页可导出 Markdown：对话、关系状态、事实、情节、成长日志
- 由宿主生成，密钥与原始音频不进入导出

### 气泡快捷回复

- 桌宠说话气泡带「继续 / 换个话题 / 记下来」按钮
- 点击后自动发一句话给宿主对话，回复仍走同一个气泡/记忆
- 目前桌面气泡有按钮；网页宠物气泡暂未加

### 语音情绪（v1）

- 语音侧用 **SenseVoice 自带的 emotion 标签**（声学/事件分类）判断用户情绪
- 标签缺失或不可用时，回退到转写文本情感
- 结果写入 `userMood`（开心/低落/生气/平静），「情感」页显示「用户情绪」
- 宠物 `mood` 仍按关系状态更新；情绪标签只用于理解用户
- 后续可接 emotion2vec+ 提升准确率

### 多宠物音色 / 人设

- 「宠物」页选择语音对话代表哪只宠物，并覆盖该宠物的音色与人设补充
- 文本对话仍按原 `main-config.jsonc` 的每只宠物人设
- 语音同一时间只代表一只宠物（多路同时语音留待后续）

## 7. 数据与文件

```
DSH_PET_HOME/
├─ main-config.jsonc       原桌宠配置（pets/动画/物理，保持原结构）
├─ companion.json          伴侣设置（不含密钥）
├─ companion-secrets.json  API Key / LiveKit secret（Windows ACL 仅当前用户）
├─ memory.json             迁移前的旧记忆（保留）
├─ conversations/memory.json  文本+语音共用的对话记忆
├─ conversations/emotion.json 情感状态（关系/情节/事实/成长日志）
├─ livekit.yaml            内置 LiveKit 配置（语音运行时生成）
├─ livekit-keys.json       LiveKit API key/secret（ACL 仅当前用户）
├─ logs.txt                应用日志
├─ main-animation/ memes/ pet/  用户素材
└─ conversations/
```

记忆结构：`{ "<entry>": { "<petId>": { "messages": [{role, content, ts}] } } }`。

> 语音模型不在数据根：`<项目>/voice/models/sense-voice/`（STT）与 `<项目>/voice/models/melo-tts/`（TTS）。

## 8. 架构

```
Electron 主进程
├─ 本机 HTTP（随机端口 + 令牌）—— 设置中心 / token / runtime / 记忆
├─ dsh-pet 宿主 apply()（配置、路由、桌面 Helper）
├─ VoiceSupervisor：按需起停 livekit-server.exe + Python Agent
├─ 隐藏语音窗：livekit-client 连接、麦克风、Agent 音频
└─ 桌宠透明窗（原有动画/物理/菜单）

Agent（Python）
└─ SenseVoice(本地 STT) → DeepSeek(LLM) → Edge TTS
```

## 9. 常见问题

| 现象                               | 处理                                                                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 设置页卡在「正在读取…」/标签点不动 | **已于 2026-10-28 修复**（设置脚本换行转义导致语法错误）。更新后仍出现：从右键菜单重新打开；并确认 `DSH_PET_HOME` 正确   |
| 设置页提示「缺少访问令牌」         | 不要手工输入地址，从右键「打开设置」进入（URL 带 `#token=`）                                                             |
| 宠物不见了、右键没反应             | 宠物 display 被设为「都不」：用系统托盘勾回「桌面位」                                                                    |
| 语音开启失败                       | 看 `data/dsh-pet/logs.txt`；确认 `DSH_PET_LIVEKIT_BIN` / `DSH_PET_PYTHON` / `DSH_PET_AGENT_ROOT` 存在                    |
| 语音没声音                         | 检查麦克风权限；设置页 LiveKit 页看运行日志；确认 Edge TTS 能联网                                                        |
| 7880 端口被占用                    | 关闭其它 LiveKit；或改设置里的端口                                                                                       |
| Edge 试听/语音报 DNS/连接失败      | 微软语音服务网络不可用：切「MeloTTS（本地离线）」并确认模型已放好                                                        |
| MeloTTS 提示未安装模型             | 把 `vits-melo-tts-zh_en` 解压到 `<项目>/voice/models/melo-tts/`（含 `model.onnx`、`lexicon.txt`、`tokens.txt`、`dict/`） |
| 文本对话报错                       | 「模型」页测试连接；确认 Key、Base URL、模型                                                                             |
| 记忆没接上                         | 确认 `conversations/memory.json` 存在；改目录后需重启应用                                                                |

pnpm install

## 11. 已知限制（P6 阶段）

- 尚未打包：依赖开发目录与环境变量；安装包/首启向导在 P8
- Agent 在 Windows 仍会派生一个 job 子进程（框架行为），内存优化靠按需启停 + 空闲回收
- 打包版尚未内置 MeloTTS 模型（170MB）：当前需手动放到 `<项目>/voice/models/melo-tts/`
- 听/想/说用气泡展示，不是独立角标；语音唤醒词是子串匹配，改词在设置页
- 情感 v1 的反思是规则模板，不是 LLM 长文总结；主动关心默认关
- 语音用量是按字符估算，不是 provider 的精确计费；文本用量优先取真实 token
- 语音情绪 v1 用 SenseVoice emotion 标签 + 文本兜底；标签准确率受模型限制
- 多宠物语音同一时间只代表一只（设置里选中的那只）；文本仍按各自人设
- 提醒需要应用/宿主进程在运行；关机期间不会补发
- 配额提醒附在回复气泡尾部，不单独弹窗；达到上限默认不阻断对话
- 语音侧的情感写入是本地文件直写，与宿主同时写时极小概率丢一次更新（下一轮会补）
- 文本对话是「气泡式流式」（生成中气泡文字逐步变长，1s 轮询），不是对话框逐 token 输出；`chat.memoryDir` 改后需重启应用
- 运行日志偶有重复行（应用日志包装与宿主 logger 叠加），不影响功能，P8 清理
- 语音识别/合成依赖本地模型与 Edge TTS 网络；Edge 失败会自动回退 MeloTTS（Melo 音色更平，只作离线兜底）
- MeloTTS 只有 speed 可调，情感表达弱于 Edge；追求音色时优先 Edge
- 唤醒词、Node Agent 尚未开始（P7/P8）

## 12. 设计参考（SurfCore）

参考 [Mieksido/surfcore](https://github.com/Mieksido/surfcore) 的工程取舍，后续计划吸收：

- **记忆分层**：衰减卡（进提示词）+ 全量归档卡（只存档），三场景共享
- **主动机制**：安静时段 / 每日上限 / 主人在聊 / 额度 / 专注模式等硬闸门
- **额度看板**：每日 token 预算、80% 提醒、100% 停
- **专注模式**：临时静音主动消息与语音
- **气泡回复按钮**：每条宠物发言可一键追问
- **语音包外置**：本地/云端语音引擎独立仓库，不塞进主包
- **文档纪律**：功能变化必须同步文档（本文档已采用）

> SurfCore 本身依赖 DSH 插件架构；我们只借鉴产品与数据设计，不照搬其 DSH 耦合。
